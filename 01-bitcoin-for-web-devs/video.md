# Module 1 video: outline (about 12 minutes)

Record in your own voice, screen plus a small face cam if you like. Pidgin subtitles get added after a native speaker reviews the script.

1. **Hook, 0:00–0:45.** "You don't have a balance in Bitcoin. You have notes." Show a ₦2,000 note paying for a ₦1,500 item, with ₦500 change.
2. **Keys and addresses, 0:45–3:00.** Run `npm run new-wallet`. Point at the `tb1q` prefix. Say what to share and what never to share.
3. **Faucet and balance, 3:00–5:00.** Paste the address into a faucet. Run `npm run balance`. Open the explorer and match the coin.
4. **Sending, 5:00–9:00.** Do a dry run first. Read the output out loud: inputs, the payment, change, fee. Then send for real and open the transaction link.
5. **Mistakes, 9:00–11:00.** Forgetting change (show the maths), committing keys, trusting unconfirmed coins.
6. **Wrap, 11:00–12:00.** Set the three exercises and tease module 2.
